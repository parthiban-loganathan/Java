Weekly Java lab

Paste your program, press Save to my repository, then Commit changes on GitHub. About a minute later GitHub has compiled your program with Java 21, run it on the official test cases and written the result into your private repository. Every version you save is kept, with the date and time, and your teacher collects them at the deadline.

First time? Set up your private lab repository (10 minutes, once)
  1. Sign in to GitHub. Open the lab template (it opens "Create a new repository").
    • Repository name: java-lab- followed by your register number in lower case, e.g. java-lab-24bcl0001.
    • Choose Private. Click Create repository.
  2. Fill in your details below (name, register number, repository) and press Open student.json; replace the file's text with the text shown, then Commit changes.
  3. Press Add my teacher; on GitHub click Add people, type , add. Only you and your teacher can see your work.

What happens after you commit

    
    
      
  1. GitHub Actions starts a fresh, isolated computer with Java 21 (no internet access for your program, 10 seconds per test).
    2. 
      
  2. Your program is compiled. Compiler errors are reported with the line number.
    3. 
      
  3. It is run with each official input of the exercise and its output is compared with the reference output (spaces at line ends ignored).
    4. 
      
  4. The report results/<exercise>.md shows which tests passed and, for the others, your output beside the expected output.
    5. 
      
  5. At each deadline your teacher's gradebook collects the latest version, grades it again with its own copy of the tests, and adds the teacher's marks.
