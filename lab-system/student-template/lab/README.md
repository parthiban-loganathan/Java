# Your lab programs

One folder per exercise, named exactly as on the lab website (`E01a`, `E02b`, `L05`, or the code your
teacher gives for a weekly task such as `W05-Q1`). Inside it:

| File | Purpose |
|------|---------|
| `Main.java` | your program (class `Main` with the `main` method) |
| `input.txt` | optional: your own keyboard input; the program is also run with it (not marked) |

Example: `lab/E01a/Main.java`.

The easiest way to save a program here is the **Weekly lab** page of the lab website: paste your code,
press **Save to my repository**, then **Commit changes**. About a minute later your results appear in
`results/` (see `results/summary.md`).
